# Estación 8 · Aseguramiento de calidad

Miércoles 4 de noviembre · Instructor: Andrés Caicedo.

## Income

- Tu rebanada corriendo en local, con el comando en el README de tu repo.
- TASK-001 mergeada y TASK-002 en curso.
- El flujo de tu rebanada escrito paso a paso.

## Outcome

Tests sobre **tu** rebanada:

1. Un flujo E2E del recorrido completo de tu rebanada.
2. Un test de API sobre el endpoint principal.
3. Si tu producto tiene un agente: un caso de evaluación con su criterio de éxito.

Los tests corren con un comando documentado y sus enlaces van al roadmap.
