# Estación 3 · Herramientas agénticas en práctica

Material de consulta: cómo funcionan los coding agents y cómo se usan Claude Code, OpenCode y Antigravity. Son 27 lecciones cortas, de 2 a 20 minutos cada una, organizadas en cuatro recorridos.

## Income

- PRD o spec de tu producto.
- Una cuenta para al menos una de las herramientas (Claude Code, OpenCode o Antigravity).

## Outcome

Un entorno agéntico funcionando en tu repo: el agente lee tu proyecto, edita, corre comandos, y tienes al menos un `CLAUDE.md` o `AGENTS.md`, un MCP conectado y una skill propia.

## Cómo usarlo en la cohorte 5

- Empieza por **Conceptos base** y después elige **una** herramienta. Claude Code es la que usamos en clase.
- Las prácticas usan un CRM de ejemplo ([30x-llc/basic_crm_30x](https://github.com/30x-llc/basic_crm_30x)). Sirve para probar sin riesgo; cuando entiendas la técnica, aplícala en **tu** repo.
- Si estás al día con E7, usa este material como referencia puntual: hooks, subagentes, MCP o skills cuando los necesites.

## Recorridos

| Recorrido | Lecciones | Qué cubre |
|---|---|---|
| [Conceptos base](conceptos.md) | 5 | El estado del arte, el bucle agéntico, del commit al artefacto, ingeniería de contexto y requisitos técnicos |
| [Claude Code](claude-code.md) | 9 | Instalación, modo interactivo, settings y permisos, memoria con `CLAUDE.md`, flujos reales, hooks, subagentes, modo headless y CI/CD, equipos de agentes |
| [OpenCode](opencode.md) | 5 | Agente open source con modelos locales o en la nube, `AGENTS.md`, MCP y skills |
| [Antigravity](antigravity.md) | 8 | Instalación, navegación, Agent Manager, editor y worktrees, artefactos y paralelismo, taller práctico |
